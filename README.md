# PhysicaLab AI - Interactive Physics Simulations Hub

Interactive web-based physics simulations with an integrated Gemini AI tutor.
Built for CBSE Class 11 & 12, NEET, and JEE physics conceptual learning.

Live demo after Vercel deploy will appear here.

## Local preview

Just open `index.html` in a browser, or run:

```bash
npx serve .
```

## Deploy on Vercel

1. Push this folder to GitHub
2. Import the repo in Vercel (Framework Preset: Other)
3. Deploy — no build step required, `index.html` is served at `/`

## Structure

- `index.html` — full app (Tailwind CDN, Lucide, KaTeX, Canvas engines)
- `vercel.json` — clean URLs config for Vercel
